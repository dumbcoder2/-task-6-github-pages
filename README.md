# Task 6: Host a Static Website with GitHub Pages

## Project Overview

This project demonstrates how to create and deploy a static website using **GitHub Pages**.

The website is built using HTML, CSS, and JavaScript and is publicly accessible through GitHub Pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Features

- Responsive website layout
- Styled using CSS
- JavaScript interactions
- Dark mode toggle
- Hosted publicly using GitHub Pages

## Deployment Steps

1. Created a static website using HTML, CSS, and JavaScript.
2. Created a GitHub repository.
3. Uploaded the project files to the repository.
4. Opened repository Settings → Pages.
5. Selected the `main` branch and `/ (root)` folder.
6. Enabled GitHub Pages and verified the live website.

## Learning Outcome

Learned how to host a static website using GitHub Pages and manage website files through Git and GitHub.
